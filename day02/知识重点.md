## 一、逻辑运算符：JS 和 C++ 最大的思维差异

### 1. && 和 || 返回"操作数本身"，不是布尔值

C++ 中 `a || b` 的类型是 `bool`；JS 中返回的是**决定结果的那个操作数**：

```js
"a" || "默认"    // "a"      左边 truthy，直接返回左边（右边根本不求值）
0 || "默认"      // "默认"   左边 falsy，返回右边
1 && 2           // 2        左边 truthy，结果由右边决定 -> 返回右边
0 && 2           // 0        左边 falsy，短路 -> 返回左边
```

**短路求值**（short-circuit）：左边能定结果时右边不再求值。实战用途：

```js
// || 惯用法：给可能为空的值设默认值
const nickname = userInput || "匿名用户";

// && 惯用法：左边成立才执行右边（近似 if 的简写）
isVip && showDiscount();
```

### 2. ?? 空值合并：|| 的"严格版"

`||` 把所有 falsy 都当成"空"；`??` 只认 `null` 和 `undefined`。

```js
const volume = 0;
volume || 50    // 50  错！把合法的 0 当成"没填"
volume ?? 50    // 0   对！0 是合法值
```

**选型口诀**：`0`、`""`、`false` 算合法值时用 `??`，其余设默认值的场景用 `||`。

### 3. ?. 可选链：安全的属性访问

```js
user?.address?.city    // 中途任何一环是 null/undefined，整体返回 undefined，不报错
obj?.fn?.()             // 方法存在才调用
```

C++ 访问空指针成员直接崩溃；JS 用 `?.` 优雅降级为 `undefined`。前端拿后端数据时天天用。

### 4. truthy / falsy（Day 1 回顾，逻辑运算符的地基）

falsy 只有 6 个：`false, 0, "", null, undefined, NaN`。其余全是 truthy，**包括 `"0"`、`[]`、`{}`**。

## 二、流程控制：同 C++，只有 4 个差异点

| 项目 | 结论 |
|------|------|
| if / else / switch / while / do-while / break / continue | 与 C++ 写法一致，直接用 |
| switch 比较 | 用 `===` 严格比较（`case "1"` 不会匹配数字 1） |
| for 循环 | 写法相同，但循环变量用 `let i = 0`（**没有 int！**漏写 let 会泄漏全局变量） |
| for...of | 遍历数组/字符串的**值**，≈ C++ range-for，数组首选 |
| for...in | 遍历**键**（属性名），给对象用，数组别用它 |

浮点陷阱：`for (let i = 0; i <= 1; i += 0.1)` 会累积浮点误差，正确做法是整数循环再除：`for (let i = 0; i <= 10; i++) (i / 10)`。

## 三、函数：今天的重头戏

### 1. 三种写法，本质相同——都是"创建一个函数值"

```js
function add1(a, b) { return a + b; }        // 函数声明
const add2 = function (a, b) { return a + b; }; // 函数表达式
const add3 = (a, b) => a + b;                 // 箭头函数
```

三者可互换使用。区别仅在细节：函数声明有"提升"（先调用后定义也能跑），表达式和箭头函数没有。

### 2. 箭头函数语法细则（必须练熟）

| 形态 | 写法 | 规则 |
|------|------|------|
| 多参数多语句 | `(a, b) => { ...; return x; }` | 有 `{}` 就必须有 `return` |
| 多参数单表达式 | `(a, b) => a + b` | 省略 `{}` 和 `return` |
| 无参数 | `() => console.log("hi")` | `()` 不能省 |
| 单参数 | `x => x * 2` | 括号可省（团队风格指南通常要求保留） |
| 返回对象字面量 | `(x, y) => ({ x, y })` | 必须套 `()`，否则 `{}` 被当成函数体 |

### 3. 参数系统

```js
function greet(name = "访客") { ... }     // 默认参数：必须从右往左连续排（同 C++ 默认实参规则）
function sum(...nums) { ... }             // 剩余参数：收集成一个真数组
sum(...arr)                                // 展开运算符：把数组摊开逐个传入
```

JS 没有引用传参（`&`）也没有传出参数——多返回值靠**返回对象/数组**：
`const [min, max] = findRange(arr);`

### 4. 函数是一等公民（理解 Vue 的钥匙）

函数可以：赋值给变量、存进数组/对象、当参数传（**回调**）、当返回值返回。

```js
function applyTwice(fn, v) { return fn(fn(v)); }
applyTwice(x => x + 1, 5);        // 7，临时箭头函数直接当参数
nums.map(n => n * 2);             // 数组方法接收回调——Vue 里 @click="handler" 同理
```

**心智转换**：C++ 传函数要用函数指针/`std::function`，显得"高级"；JS 传函数像传数字一样平常。之后 Vue 的 props 传回调、事件处理都建立在这上面。

### 5. 闭包雏形（现象级理解，Day 9 深挖）

```js
function makeCounter() {
  let count = 0;
  return () => ++count;   // 内层函数"记住"了外层的 count
}
const c = makeCounter();
c(); c(); c();             // 1 2 3 —— count 没有被销毁
```

记住现象即可：**函数可以携带它定义时所处环境的变量一起存活**。

### 6. JS 没有函数重载

同名函数后定义的覆盖前面的。替代方案：参数类型在函数内用 `typeof` 自己判断。

## 四、Day 2 易错点清单（自测）

1. `"" || "默认"` 输出什么？（→ `"默认"`）
2. `0 ?? "默认"` 输出什么？（→ `0`，?? 不把 0 当空）
3. `for` 循环变量漏写 `let` 会怎样？（→ 泄漏为全局变量）
4. 箭头函数 `x => { x * 2 }` 返回什么？（→ `undefined`！有 `{}` 无 `return`）
5. `(x, y) => {x, y}` 返回什么？（→ `undefined`，要写 `({x, y})`）
6. `sum(...[1,2,3])` 和 `sum(1,2,3)` 等价吗？（→ 等价，展开运算符）
7. JS 能否像 C++ 一样函数重载？（→ 不能，覆盖）
8. `for...in` 和 `for...of` 分别遍历什么？（→ 键 / 值）
